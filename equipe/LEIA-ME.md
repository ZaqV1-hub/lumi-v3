# Início do desenvolvimento da Lumi

O repositório da equipe é https://github.com/ZaqV1-hub/lumi-v3. O acesso depende de convite e autenticação da conta GitHub de quem vai trabalhar. Não envie senhas, tokens ou códigos no chat. A mensagem de início está em `MENSAGEM-PARA-CODEX.txt`; ela pode ser colada no Codex depois de abrir a pasta local do projeto, ou enviada com este pacote para preparar a cópia de trabalho.

O pacote de orientação contém `AGENTS.md` para a raiz do projeto e a pasta `docs/` com os guias de desenvolvimento, arquitetura, contratos e operação. Ele contém somente documentação, não o código da aplicação nem configurações privadas. Caso o repositório ainda não tenha esses arquivos, peça ao Codex para incorporá-los, comparando antes qualquer arquivo existente. Não substitua uma versão mais recente sem revisão. O arquivo AGENTS.md é lido pelo Codex no contexto do projeto; anexar documentos ao chat não configura automaticamente outros projetos ou todas as conversas futuras.

Antes de desenvolver, confirme que o código obtido é a versão de referência combinada pela equipe. Este pacote não publica alterações locais que ainda não tenham sido enviadas ao GitHub. Se o código esperado não estiver no remoto, obtenha a versão correta com a equipe antes de aplicar mudanças. Clonar o repositório não instala dependências, não fornece bancos e credenciais, nem ativa WhatsApp ou Instagram.

Depois da preparação, o desenvolvedor descreve a tarefa em linguagem natural. O guia `docs/desenvolvimento-e-passagem.md` contém exemplos para configuração de tenant, criação de serviço e correção do núcleo. O Codex deve seguir as regras do repositório, executar os testes pertinentes e informar o que foi comprovado. A publicação é uma etapa separada, conforme o escopo autorizado.
